# @deepseek-ai/dsh-client-ui-settings-mcp-servers

[English](README.md) | 中文

## 概述

在侧栏打开**插件**，在官方分组里选择 **MCP 服务器**，即可在不编辑文件的情况下添加、编辑、启用、停用和移除当前 profile 的 MCP 服务器。每个服务器是一个本地命令或一个 HTTP 端点。密钥以环境变量的形式选择，从不直接键入 profile 文件。输入框下方的状态项显示已连接的服务器数量，并可打开它们的用量数据。页面和状态项只在 Host 提供 `mcpServers` Remote 期间存在。

<a id="use-this-package"></a>
## 使用本包

**MCP 服务器**卡片打开服务器列表。每一行显示服务器的名称、类型、连接状态，以及命令或 URL。状态显示为**已连接**、**连接中**、**重连中（尝试次数/上限）**或**未连接**，未连接的服务器会在命令下方显示最近一次错误。开关用于启用或停用服务器，**工具（n）**打开该服务器的工具，**重新连接**会立即连接而不再等待重试延迟，**编辑**打开表单，**移除**会先询问。**添加服务器**为新服务器打开同一个表单。

表单需要填写**名称**（字母、数字、`_` 和 `-`，它是该服务器工具名称的前缀）、类型，以及命令（每行一个参数，可选工作目录）或 URL。本地命令以最小环境启动（路径、主目录、区域设置和代理设置），因此它需要的其他变量必须列出。**环境变量**（本地命令）或**请求头**（HTTP）列出名称和值：每个值可以是服务器启动时从 harness 环境读取的**环境变量**（该变量必须已设置）、以 `Bearer <值>` 发送的 **Bearer 变量**，或纯**文本**。形似凭证的名称（如 `TOKEN` 或 `Authorization`）不接受纯文本。文件中已有的存储值显示为**已存储的值**，文件中已有的表达式显示为**表达式**，二者都保持原样。表单还包含工具调用超时、服务器必须连接成功插件才启动的选项，**新会话默认启用**（关闭后，服务器仍然可用，但会话只有在选择它之后才会使用），以及**工具调用**：对服务器提供的所有工具选择**先询问**（默认）、**允许**或**阻止**。允许或阻止调用的服务器在行上带有标签。

保存本地命令前，会先显示 harness 将要运行的完整命令，并请用户确认信任。服务器可以编辑，但不能更改类型。

**工具**对话框按模型看到的名称列出每个工具，附带说明的第一行和一个筛选框。选择一个工具即可查看完整说明，以及列出各参数类型和是否必填的参数表。对话框打开期间列表会随之更新。每个工具显示其运行模式，展开后的说明中有一个**模型调用此工具时**选择框，可为它单独指定模式或恢复为服务器默认；这些修改在下一次调用时生效，不会使服务器重新连接。在 MCP 工具调用的审批提示中，**始终允许**以同样方式把该工具设为允许，然后允许本次调用。

### 状态项

在对话中，输入框下方、其他读数旁边会出现 **MCP 2/3** 一项：已启用的服务器中已连接的数量，其圆点在服务器连接中时变为琥珀色，在有服务器失败时变为红色。选择它会打开一个面板。顶部分别按**本会话**和**全部会话**显示调用次数、错误次数、估算的输入和输出 Token 数，然后是本会话所用服务器的工具定义为每次请求增加的估算 Token 数。随后每个服务器显示其状态、决定本会话是否使用它的开关、以“本会话 / 全部会话”形式给出的同样四个数字，以及一个**详情**行，包含服务器自报的名称和版本、协议版本、类型、已连接时长、连接次数、工具数量、平均和最慢调用耗时、上次调用时间，以及最常用的五个工具。面板打开期间数据每两秒刷新一次。**管理服务器**会打开插件页。

MCP 服务器页上的**在输入框下方显示 MCP 状态**用于打开或关闭该项。这一选择随 profile 的设置保存，默认开启。没有配置任何服务器时该项不会显示。

### 按会话选择服务器

添加服务器只是让它可用；每个会话自行决定使用哪些服务器。在输入框工具行中，权限选择器和模型选择器之间有一个 **MCP 2/3** 选择器，显示本会话使用了多少个已启用的服务器。它打开服务器列表，正在使用的服务器带有勾选标记；选择某个服务器会为本会话切换它，列表保持打开，取消全部勾选则不使用任何服务器。状态面板中的开关作用相同。选择器出现在新会话界面和对话中，更改从会话的下一次请求开始生效。

尚未选择的会话使用所有开启了**新会话默认启用**的服务器。会话的选择随会话保存，因此重启后仍然有效；子 agent 以父会话的选择开始。未连接的服务器仍可选择，其名称旁会注明状态。

在支持热重载的 profile 上更改会立即生效，否则提示需要重启。来自 bundle、家目录补丁或命令行覆盖的行会列出，但不能在此更改；使用表达式的行或带凭证的 URL 的行可以移除或切换，但不能编辑。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节——点击展开</summary>

Host 部分是一个空的 `apply`，仅用于让包拥有一个 Loader 行，客户端模块系统据此为其提供浏览器部分。浏览器部分由 `McpServersController` 维护页面：读取 `mcpServers.list`，把表单暂存为 `EditorDraft`，并用 `specFromDraft` 把草稿转换为 `McpServerSpec`。被拒绝的保存会回到表单，显示针对 Host 错误码的本地化语句，并在旁边附上 Host 自己的说明。本地命令要保存两次：第一次调用被 `confirmation-required` 拒绝并返回 Host 的命令行；用户确认信任后，第二次带着这段完全相同的文本作为 `confirmedCommand` 重复提交，因此用户读到的文本就是 Host 校验的文本。控制器在每次更改之后，以及收到 `plugin-manager/changed` 和 `connection/reset` 时重新读取，但只在页面打开之后才这样做。

页面把 `McpServersCard` 注册到插件页的 `plugins.item` 插槽，把 `McpServersToast` 注册到 `shell.overlay`，使结果提示在插件面板关闭后依然存在。状态项是注册在输入框 `conversation.composer.dock` 插槽中的 `McpStatusItem`，选择器是注册在 `conversation.input.right` 中的 `McpServerSelect`，二者由同一个 `McpTrayController` 驱动：任一组件挂载时以及 Host 报告变化时，它为当前显示的会话读取 `mcpServers.overview`，并且只在面板打开期间轮询，因为用量计数不触发事件。二者都读取会话的 `mcpServers` 投影，并用 `useSessionServers` 解析正在使用的服务器：已记录的选择，或在没有记录时使用各服务器的默认值。切换会立即显示，通过 `mcpServers.setSessionServers` 发送完整的选择，并让位于会话日志的下一次选择或一次拒绝。没有该投影（即 Host 未挂载选择服务）时，选择器和开关都不出现。偏好设置是本包 Host 部分的 `statusItem` 字段，这是一个实时设置字段，通过 `ctx.configForms` 以命名空间 `ui-settings-mcp-servers` 读写。

包注入 `remote.mcpServers`，因此没有该控制器的部署中不会出现这个页面、状态项和选择器。

</details>

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- **连接状态依赖状态服务** — 随附 profile 会挂载它；没有它时，插件启动后该行就显示**已加载**，即使服务器从未连接成功。
- **错误是服务器自己的文本** — 连接错误按 SDK 或传输层的原样显示，未经本地化。
- **并非所有值都可编辑** — 在 `env` 和 `headers` 之外使用表达式的行，或 URL 内嵌凭证的行，可以移除或切换，但不能编辑。
- **浏览器侧校验很少** — 完整配置由 Host 校验，表单会显示 Host 拒绝的内容。
- **状态项需要一个对话** — 空白会话的起始界面不渲染输入框下方的区域，因此对话有了消息之后该项才会出现。
- **用量数据以进程为单位且为估算** — 计数在 harness 重启时清零，且不按 Session 拆分；Token 数是按每 Token 四个字符的文本长度计算的。
- **运行时 invariant：** 不发布伴生包。页面不持有自己拥有的关系：显示的内容来自 `mcpServers.list`，写入的内容由 Host 校验。
