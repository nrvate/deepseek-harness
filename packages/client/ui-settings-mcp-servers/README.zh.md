[English](README.md) | 中文

## 概述

在侧边栏打开 **插件**，在官方分组中选择 **MCP 服务器**，即可在不编辑文件的情况下添加、编辑、测试、启用、停用和移除 [MCP 管理器](../../mcp/mcp-manager/README.zh.md)所运行的服务器。每个服务器是一个本地命令或一个 HTTP 端点。密钥保存在凭据存储中，配置设置只保存其名称。输入框下方的状态项显示已连接的服务器数量，并可打开其用量数据。只有当 Host 提供 `mcpManager`、`mcpServers`、`settings` 和 `credentials` Remote 时，该页面和状态项才会出现。

<a id="use-this-package"></a>
## 使用本包

**MCP 服务器** 卡片会打开列表。每一行显示服务器的名称、类型、实时状态以及命令或 URL，并用标签说明其来源：**来自配置**、**已修改配置值**、**由插件注册**，在此添加的服务器则没有标签。状态为 **已连接**、**正在连接**、**正在重连（次数/上限），… 后重试**、**等待凭据**、**未连接**、**关闭** 或 **清理未完成**，最近一次错误显示在命令下方。开关用于启用或停用服务器，**工具 (n)** 打开该服务器的工具，**重新连接** 会重启已停止尝试、正在等待重试或等待凭据的服务器，**测试** 会独立于运行中的实例连接服务器并报告其提供的内容，**编辑** 打开表单，**移除** 删除在此添加的服务器，**恢复默认** 丢弃对来自配置的服务器所做的更改。插件注册的服务器可以测试并设置其工具，但不能编辑。**添加服务器** 打开同一表单以添加新服务器。

表单需要填写 **名称**（字母、数字、`_` 和 `-`；它会作为该服务器工具名称的前缀）、类型，以及每行一个参数的命令和可选的工作目录，或者一个 URL。本地命令以最小环境启动（其路径、主目录、区域设置和代理设置），因此它需要的其他变量都必须列出。**环境变量**（本地命令）或 **请求头**（HTTP）列出名称与值；每个值可以是纯 **文本**、**凭据**，或者对请求头而言以 `Bearer <value>` 发送的 **Bearer** 凭据。凭据指向凭据存储中的一个条目，名称会根据服务器名和值名建议；在旁边输入密钥会在保存时将其存入凭据存储，并有标签显示存储中是否已有值。设置中只保存 `${credential:NAME}`。表单还可设置工具调用超时、**新会话默认开启**（关闭时服务器仍可用，只有在会话中选择后才会使用），以及 **工具调用**：对该服务器提供的每个工具选择 **先询问**（默认）、**允许** 或 **阻止**。调用被允许或被阻止的服务器会在行上带有标签。

保存新的或更改过的本地命令时，会先显示 harness 将要运行的确切命令，并请用户确认信任。服务器可以编辑，但名称和类型不能更改。

**测试** 对话框显示服务器报告的名称和版本、连接和列出工具所用的时间及其工具名称；失败时显示失败的阶段和服务器的消息；测试连接未能正常关闭时也会说明。

**工具** 对话框以模型看到的名称列出每个工具，附带描述的第一行和一个筛选框。选择某个工具可阅读其完整描述，以及列出参数类型和是否必填的参数表。每个工具都会显示其运行模式，展开的帮助中有 **模型调用此工具时** 选择框，可为它单独设置模式或恢复为服务器默认值；这些更改在下一次调用时生效，无需重新连接服务器。在 MCP 工具调用的审批提示中，**始终允许** 会以同样方式把该工具设为允许，然后允许本次调用。

### 状态项

在对话中，输入框下方与其他读数并列显示一个 **MCP 2/3** 状态项：已连接的服务器数量与已启用数量之比，其圆点在服务器连接中时变为琥珀色，有服务器失败时变为红色。选择它会打开一个面板。顶部显示 **本会话** 和 **所有会话** 的调用次数、错误次数以及估算的输入和输出 token，然后是本会话所用服务器的工具定义为每个请求增加的估算 token。随后每个服务器显示其状态和最近错误、一个决定本会话是否使用它的开关、同样的四项数据（本会话 / 所有会话），以及一个 **详情** 行，包含服务器报告的名称和版本、协议版本、类型、已连接时长、连接次数、工具数量、平均和最慢调用、最近一次调用，以及最常用的五个工具。面板打开时数据每两秒刷新一次。**管理服务器** 会打开插件页。

MCP 服务器页面上的 **在输入框下方显示 MCP 状态** 用于开关该状态项。该选择随配置的设置保存，默认开启。未配置任何服务器时状态项不会显示。

### 按会话选择服务器

添加服务器只是让它可用；每个会话自行决定使用哪些服务器。在输入框工具栏中，权限和模型选择器之间有一个 **MCP 2/3** 选择器，显示本会话使用了多少个正在运行的服务器。它会打开服务器列表，正在使用的服务器带有勾选；选择某个服务器会为本会话切换它并保持列表打开，取消所有勾选则不使用任何服务器。状态面板中的开关作用相同。选择器出现在新会话界面和对话中，更改从会话的下一个请求开始生效。

尚未选择的会话会使用所有 **新会话默认开启** 的服务器。会话的选择随会话保存，因此重启后仍然有效，子代理会继承其父级的选择。未连接的服务器仍可被选择，并会在名称旁注明。

所有更改都无需重启即可生效：管理器只会启动、重建或停止发生变化的服务器，工具模式在下一次调用时生效。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节——点击展开</summary>

Host 部分注册状态项偏好设置，并让自身的 fiber 不出现在自动生成的设置页面中。浏览器部分通过 `McpServersController` 维护页面。它用 `settings.describe` 读取三个 Settings 命名空间：`mcp-manager` 中的服务器条目（解析值、配置基础层和用户层）、`mcp-policy` 中的工具模式，以及 `mcp-selection` 中每个服务器的默认值。`joinRows` 将它们与来自 `McpFleet` 的管理器实时列表合并；`McpFleet` 为页面、状态项和选择器持有同一个 `mcpManager.watch` 流，并在 `connection/reset` 时重新打开它。表单暂存为 `EditorDraft`；`entryFromDraft` 将其写在已存储的条目之上，因此表单不编辑的字段（例如 `reconnect`）得以保留。保存时先用 `credentials.set` 存储输入的密钥，然后按读取时的 revision 用 `settings.mutate` 写入 `servers.<name>`，再在策略默认值和会话默认值有变化时写入它们。启用和停用设置 `servers.<name>.enabled`；移除和恢复会取消设置 `servers.<name>`，对继承的服务器而言会保留配置中的条目。被拒绝的写入会在表单或提示中显示 Host 的说明。重启和测试调用 `mcpManager.restart` 和 `mcpManager.probe`；关闭正在进行的测试会中止它。控制器在这三个命名空间的 `settings/document-updated`、`plugin-manager/changed` 和 `connection/reset` 时重新读取，但仅在页面打开过之后。

页面将 `McpServersCard` 注册到插件页的 `plugins.item` 插槽，并将 `McpServersToast` 注册到 `shell.overlay`，使结果提示在插件面板关闭后仍然可见。状态项是位于输入框 `conversation.composer.dock` 插槽中的 `McpStatusItem`，选择器是位于 `conversation.input.right` 中的 `McpServerSelect`，两者由同一个 `McpTrayController` 支持：它将管理器列表与当前会话的 `mcpServers.overview` 合并，在任一组件挂载时以及 Host 报告变更时读取，并且只在面板打开时轮询，因为用量计数不会触发事件。不由管理器运行的客户端（例如配置中的行）仍会连同其用量一起显示。两者都读取会话的 `mcpServers` 投影，并用 `useSessionServers` 解析正在使用的服务器：已记录的选择，或在没有记录时使用每个服务器的默认值。切换会立即显示，通过 `mcpServers.setSessionServers` 发送完整选择，并让位于会话日志中的下一次选择或拒绝结果。没有该投影即表示 Host 未挂载选择服务，此时选择器和开关都不会出现。偏好设置是本包 Host 部分的 `statusItem` 字段，是一个通过 `ctx.configForms` 在命名空间 `ui-settings-mcp-servers` 下读写的实时设置字段。

本包注入 `remote.mcpManager`、`remote.mcpServers`、`remote.settings` 和 `remote.credentials`，因此在缺少它们的部署中，页面、状态项和选择器都不会出现。

</details>

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- **继承的值无法删除** — Settings 按键将用户覆盖合并到配置的条目中，因此即使表单删除了配置所设置的环境变量或请求头，它仍会保留；**恢复默认** 会让整个服务器回到配置中的条目。
- **管理器之外的配置行不会列出** — 配置中的 `mcp-client` 行仍会运行并显示在状态项中，但页面不会列出或编辑它。
- **名称无法更改** — 重命名服务器需要先移除，再以新名称添加。
- **错误为服务器原文** — 连接或探测错误按 SDK 或传输层报告的原文显示，未做本地化。
- **浏览器端校验很少** — 页面只检查名称、超时和凭据名称；管理器会在写入时校验整个条目，表单显示被拒绝的内容。
- **状态项需要对话** — 空白会话的开始界面不渲染输入框停靠区，因此对话有消息后状态项才会出现。
- **用量数据按进程统计且为估算** — 计数在 harness 重启后清零；token 数据按每四个字符一个 token 估算文本长度。
- **运行时不变量：** 不发布任何伴随项。页面自身不持有关系：它显示的内容来自 Settings、管理器列表和 `mcpServers.overview`，它写入的内容由 Host 校验。
